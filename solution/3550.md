You are given an integer array nums.

Return the smallest index i such that the sum of the digits of nums[i] is equal to i.

If no such index exists, return -1.

 

Example 1:

Input: nums = [1,3,2]

Output: 2

Explanation:

For nums[2] = 2, the sum of digits is 2, which is equal to index i = 2. Thus, the output is 2.
Example 2:

Input: nums = [1,10,11]

Output: 1

Explanation:

For nums[1] = 10, the sum of digits is 1 + 0 = 1, which is equal to index i = 1.
For nums[2] = 11, the sum of digits is 1 + 1 = 2, which is equal to index i = 2.
Since index 1 is the smallest, the output is 1.
Example 3:

Input: nums = [1,2,3]

Output: -1

Explanation:

Since no index satisfies the condition, the output is -1.
 

Constraints:

1 <= nums.length <= 100
0 <= nums[i] <= 1000

## Approach

We check each index `i` in order and compute the sum of digits of `nums[i]`.

- If the digit sum equals the current index, return `i` immediately.
- Otherwise, continue scanning.
- If no valid index exists, return `-1`.

This works because the problem asks for the smallest valid index, and iterating from left to right guarantees the first match is the smallest.

## Java Solution

```java
class Solution {
    public int smallestIndex(int[] nums) {
        for (int i = 0; i < nums.length; i++) {
            if (digitSum(nums[i]) == i) {
                return i;
            }
        }
        return -1;
    }

    private int digitSum(int n) {
        int sum = 0;
        while (n > 0) {
            sum += n % 10;
            n /= 10;
        }
        return sum;
    }
}
```

## Why this is correct

For each index `i`, the function `digitSum(nums[i])` calculates the sum of all digits in the value at that index. If that value equals `i`, then the condition from the problem is satisfied.

Because we iterate from `i = 0` to `nums.length - 1`, the first index that satisfies the condition is the smallest valid index.

## Complexity

- Time: `O(n * d)`, where `d` is the number of digits in the value, at most 4 here
- Space: `O(1)`
